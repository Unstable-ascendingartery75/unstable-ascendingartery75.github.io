  • 📂 Multiple AI Tools Supported — Works with Claude Code, Codex CLI, Cursor, OpenCode, Copilot CLI, Kimi Code, and more. Add new ones as needed.

📖 How to Use

  1. Launch the app — Double-click the ai-session-search icon on your desktop or start menu.
  2. Point to your sessions folder — The first time, you'll be asked to select the folder where your AI session files are stored. This is usually a folder like Documents\Claude Sessions or %APPDATA%\Cursor\Sessions. The app will scan that folder.
  3. Wait for indexing — The first scan may take a minute or two. After that, new sessions are added automatically.
  4. Search — Type a word, phrase, or code snippet into the search box. Results appear as you type.
  5. Click a result — Select any session to view its full content in a readable format. You can scroll through the entire conversation.
  6. Filter by tool — Use the dropdown menu to show only sessions from Claude Code, Cursor, or any other tool.
  7. Close when done — The app saves your index automatically. Your searches are ready next time.

That's it! No command line, no coding, no configuration files.

❓ Frequently Asked Questions

Is this safe to use?

Yes. The tool is read-only and never modifies your files. It only reads them to build a search index. All data stays on your computer.

Do I need to install anything else?

No. The download includes everything you need. Just run the installer.

What if I have thousands of sessions?

No problem. The tool uses SQLite for fast indexing. Searches remain fast even with 10,000+ sessions.

Can I search across multiple folders?

Yes. You can add multiple folders to the index. The tool will search all of them together.

Does it work on Mac or Linux?

This version is for Windows. Mac and Linux versions are coming soon.
